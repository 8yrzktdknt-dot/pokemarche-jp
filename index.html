Comment fonctionne la recherche ?

Ton mot est d'abord cherché dans les noms de cartes françaises (par exemple « Pikachu », « Pikachu ex », « Pikachu V »). L'appli en déduit le numéro de Pokédex du Pokémon, puis affiche toutes les cartes japonaises dont le nom contient ce Pokémon. Les noms de cartes sont traduits en français quand c'est possible (le nom japonais reste affiché en petit). Si le nom n'existe pas en français, elle essaie en anglais, puis directement dans les noms japonais.

Seules les raretés supérieures sont gardées (RR, RRR, AR, SR, SAR, UR, MA, MUR, FUR, etc.). Un code complet comme « M6-110 » affiche toujours la carte demandée, quelle que soit sa rareté. Un code d'extension seul (« M6 »), ou le choix d'une extension dans le menu, liste ses cartes de rareté supérieure.

L'appli se concentre sur les blocs Écarlate & Violet et Méga-Évolution. Les extensions de ces deux blocs apparaissent automatiquement dans le menu dès que TCGdex les ajoute.

Les cartes sans Pokémon (Dresseur, Énergie) ne peuvent pas être reliées à leur version japonaise par ce moyen.

D'où viennent les prix ?

Le catalogue et, quand elles existent, les données de prix Cardmarket (en euros) viennent de l'API publique TCGdex. Toutes les cartes japonaises n'ont pas de prix automatique : dans ce cas, ouvre la recherche Cardmarket depuis la fiche et saisis un prix de référence, enregistré sur cet appareil. Le graphique montre l'évolution entre la moyenne sur 30 jours, 7 jours et 24 h. Chaque fois que tu ouvres une fiche avec un prix, le prix du jour est mémorisé sur cet appareil pour construire un historique.
